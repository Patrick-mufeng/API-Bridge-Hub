pytest-only. conftest is what redirects the account store to a temporary
directory and clears RELAY_API_KEYS. Without it, src.main imports the
developer's working-tree .env, API_KEYS becomes the real key, and every
unauthenticated API request returns 401 instead of the expected 200/400.
Verified: with conftest preloaded the same suite is green.

So these failures are an artifact of the runner, not CLI-subprocess or
model-probe environment problems. Run the suite under pytest, or preload
tests.conftest, to get a meaningful result.
