# BridgeHub 快速上手（便携版）

解压后 **双击 `start.bat`**，浏览器会自动打开 http://localhost:3000。无需安装 Node、Python、Go 或任何依赖，运行时已内置在 `runtime/` 目录。

> **解压提示**：请用 **7-Zip 或资源管理器右键解压**。PowerShell 的 `Expand-Archive` 对上百 MB 的包会静默少解压，导致启动文件缺失。

## 第一次使用

1. **创建管理员账号**：首次打开页面进入初始化向导，自己设定管理员用户名和密码（只存本机）。
2. **登录**：用刚建的账号登录控制台。
3. **创建 API 密钥**：「API 密钥」页点「创建 API 密钥」，复制 `sk-` 开头的密钥。该页顶部有完整连接教程。
4. **接入客户端**：客户端 Base URL 填 `http://localhost:3000/v1`，填入刚复制的密钥。

## 关于反代服务（重要）

包内自带 5 个反代服务，随主站自动启动。「反代服务」面板里能看到每个服务的状态，点「打开面板」进入它自己的控制台。

| 服务 | 模型前缀 | 开箱可用？ | 说明 |
| --- | --- | --- | --- |
| **OpenCode Zen** | `ocz:` | ✅ **可以** | 匿名免费通道，无需任何登录 |
| **CmdGo** | `cg:` | ⚠️ 需 OAuth | 打开面板完成 OAuth 登录后可用 |
| **WorkBuddy** | `wb:` | ⚠️ 需登录 | 打开面板用**你自己的**账号登录 |
| **Cline** | `cl:` | ⚠️ 需登录 | 打开面板用**你自己的**账号登录 |
| **Trae** | `tr:` | ⚠️ 需填 token | 见下方说明 |

**关于「运行异常」状态**：登录上游账号之前，这几个服务显示「运行异常 / health check returned HTTP 50x」是**正常的**。它们的健康检查只有在有可用账号时才返回成功。**在对应面板里登录你自己的账号后，状态会自动转为正常**，模型也随之可用。

**关于 Trae**：它需要 Trae 的登录凭据才能启动。打开 `trae-free-master\.env`，按文件内注释把 `TRAE_AUTH_SOURCE` 改成 `manual` 并填入 `TRAE_MANUAL_TOKEN`（或改成 `env` 填入 `TRAE_TOKEN` 等）。没填就无法启动，属预期行为。若你暂时不用 Trae，可在「反代服务」面板把它停掉。

**Qoder 不包含在本包中**（上游项目未附开源许可证）。如你自行取得其源码，放入本目录并新增一份 manifest 即可接入，格式参考现有 manifest。

## 日常使用

- **启动**：双击 `start.bat`
- **停止**：关掉那个黑窗口（或 Ctrl+C）
- **数据位置**：全部在解压目录内 —— `new-api-main\one-api.db`（账号/渠道/配置/统计）、`var\`（部分服务的密钥与状态）。**备份就备份整个目录**，删除目录即彻底清理。
- **端口**：主站 3000，各反代 7873（WorkBuddy）/ 8972（Cline）/ 8962（OpenCode Zen）/ 8015（Trae）/ 11445（CmdGo）

## 常见问题

**Q：双击 start.bat 闪一下就没？**
看是不是已经在运行（任务管理器里有 `new-api-dev.exe`）。这次窗口会停住并显示原因，读那条错误即可。

**Q：某个服务一直「运行异常」？**
99% 是还没在该服务的面板里登录上游账号。点「打开面板」登录，状态就会转正常。

**Q：端口被占用？**
改 `new-api-main\.env` 里的 `PORT`，以及 `new-api-main\data\reverse-proxy\services\*.json` 里各服务的 `port`。

**Q：控制台日志是乱码？**
用 `start.bat` 启动（它会把控制台切到 UTF-8）。直接跑 exe 会因 Windows 默认 GBK 代码页而乱码。

## 合规提醒

各反代服务依赖第三方平台的账号与接口，请自行确认使用方式符合对应平台的服务条款。本包仅供个人学习与自用。
