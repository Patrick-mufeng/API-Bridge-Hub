# BridgeHub 快速上手（便携版）

解压后 **双击 `start.bat`**，浏览器会自动打开 http://localhost:3000。无需安装 Node、Python、Go 或任何依赖，运行时已内置在 `runtime/` 目录。

## 第一次使用

1. **创建管理员账号**：首次打开页面会进入初始化向导，自己设定管理员用户名和密码（这个账号只存在于你本机）。
2. **登录**：用刚建的账号登录，进入控制台。
3. **创建 API 密钥**：「API 密钥」页点「创建 API 密钥」，复制 `sk-` 开头的密钥。该页顶部有完整的连接教程。
4. **接入客户端**：把客户端（Cherry Studio、NextChat、Cline 等）的 Base URL 设为 `http://localhost:3000/v1`，填入刚复制的密钥。

## 关于反代服务

包内自带 5 个反代服务，会随主站自动启动：

| 服务 | 模型前缀 | 需要登录上游账号 |
| --- | --- | --- |
| WorkBuddy | `wb:` | 是 |
| Cline | `cl:` | 是 |
| OpenCode Zen | `ocz:` | 否（匿名通道） |
| Trae | `tr:` | 是 |
| CmdGo | `cg:` | 是（OAuth） |

在「反代服务」面板里，每个服务都有「打开面板」按钮：**先用你自己的账号在那个面板里完成登录**（这些账号是你本人的，只能自己登），登录后模型才会出现在渠道里。OpenCode Zen 无需登录，开箱可用。

## 日常使用

- **启动**：双击 `start.bat`
- **停止**：关掉那个黑窗口（或 Ctrl+C）
- **数据位置**：`new-api-main\one-api.db`（账号/渠道/配置/统计都在这里），**备份就备份这个文件**
- **端口**：主站 3000，各反代 7873 / 8972 / 8965 / 8015 / 11445

## 常见问题

**Q：双击 start.bat 闪一下就没了？**
先看是不是已经在运行（托盘/任务管理器里有 `new-api-dev.exe`）。窗口这次会停住并显示原因，读那条错误即可。

**Q：某个服务显示"运行异常"？**
多数是还没在该服务的面板里登录上游账号。点进那个服务面板登录，状态就会转正常。

**Q：端口被占用？**
改 `new-api-main\.env` 里的 `PORT`，以及 `new-api-main\data\reverse-proxy\services\*.json` 里各服务的 `port`。

**Q：想加第 6 个服务（Qoder）？**
Qoder 未包含在本包中（上游未附许可）。如你自行取得其源码，放进目录并新增一份 manifest 即可，格式参考现有 manifest。

## 合规提醒

各反代服务依赖第三方平台的账号与接口，请自行确认使用方式符合对应平台的服务条款。本包仅供个人学习与自用。
